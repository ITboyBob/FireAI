# 文档索引

本文件是仓库文档注册表。它只回答“有哪些文档、各自负责什么、何时读取、谁更权威”；具体读取流程见 [文档读取规则](./文档读取规则.md)。

## 角色说明

- `system_meta`：代理启动、读取和工具级规则。
- `repo_overview`：项目介绍、安装、运行和入口导航。
- `architecture_or_strategy`：产品、技术架构、专项设计和决策。
- `project_or_workflow`：可执行任务步骤和验收方式。
- `reference_material`：仅用于历史追溯的背景资料。

## 存储约定

- `docs/` 下按角色建立同名目录，仓库内文档应存入对应角色目录。
- 根目录 `AGENTS.md`、`README.md`、`CLAUDE.md` 与 `.claude/rules/` 因工具入口约定保留原位，但仍按本索引登记角色。
- 超过 500 行的历史或执行文档必须拆成入口总览与分卷；总览负责导航，分卷负责具体正文。
- 空的 `docs/repo_overview/` 用于保持角色目录完整；当前项目概览仍由根目录 `README.md` 唯一承担。

## 注册规则

- 新增、移动、重命名或删除文档时，必须同步本注册表。
- 未注册文档不得参与运行时决策；发现遗漏时先补充角色和权威级别。
- 每份 Markdown 文档不得超过 500 行；接近上限时按职责边界拆分为总览与分卷。
- 生成文件、缓存、依赖文档和原始法规材料不进入本注册表，也不得作为仓库运行规则。
- 工具权限配置可以阻止某项操作，但不得被解释为修改产品、技术或仓库政策。
- 本仓库不设置个性化 `memory_layer`；跨会话稳定规则统一由 `AGENTS.md` 和本文件管理。
