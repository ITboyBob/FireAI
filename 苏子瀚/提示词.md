# 要求
## Schema定义

### 实体类型：
**注意**：提取到的每一个实体在语义上必须是一个名词或者名词性短语。禁止将“动宾短语”“动词短语”作为实体。例如，当原文为“确定消防安全重点单位”时，实体应该是“消防安全重点单位”，而不是“确定消防安全重点单位”。

- 社会团体：社会层面上的组织、团体、机构等。正例：企业、事业单位、机关、工程监理单位、消防安全重点单位等；反例：国务院、各级人民政府消防救援机构等政府部门

- 消防设施：开展消防工作需要使用的设施/设备/标志等，如“消防设施、器材”“消防安全标志”“公共消防装备”等

- 消防文件：与消防工作有关的文书、规划、档案等严谨公文资料，如“消防安全重点单位名单”
- 消防知识：除“消防文件”外的，蕴含开展消防工作所需要的知识性内容。如“教育、教学、培训的内容”。

- 政府机构：隶属国家且发挥管理、行政、监管等国家职能的机构，如”国务院“”产品质量监督部门““消防救援机构”等；反例：“消防安全重点单位”“事业单位”

- 人民群众：单个人或者体现单个人概念的词语，如“个人”“成年人”等

- 工作类型：具有特定性质或与某领域相关的工作，如“消防工作”

- 消防规范：需要遵循的消防技术标准，消防规范，消防制度；也包括编写的纸质资料。例子：“巡查记录”，“消防安全责任制”等

- 安全管理活动：对设备、文件和消防工作的维护、检查、审查和管理活动。如“消防设计文件审查”，“消防验收”，“本单位的消防安全管理工作”等

- 宣传教育活动：为宣传消防知识、培养消防意识而开展的活动，以及通过表彰、奖励等方式进行消防宣传教育的活动。如“消防安全防范服务”，“消防演练”，“经常性的消防宣传教育”，“消防公益活动”，“消防安全培训”等

- 应急处置活动：为处置某突发事件而开展的活动，既包括突发事件发生时采取的行为，也包括突发事件结束之后采取的调查工作。如“有组织的灭火工作”，“调查火灾原因”，“保护火灾现场”等

- 技术创新活动：开展的科学研究、技术创新等活动，如“消防科学研究”，“消防技术创新”。

- 消防系统建设：为完善消防力量建制、消防系统建设而进行的行为，如“建立应急救援调度指挥系统”，“制定应急反应和处置机制”，“建立公安消防队”等。

- 责任主体：承担消防工作责任的个人，如“消防安全管理人”。

- 地点：地理意义上的某块区域，如“消防安全重点部位”。

- 消防安全状态：当前消防工作状况，例子：“消防安全”，“火灾”，“火警”。

- 消防设施状态：消防设施设备的情况、状态，如“疏散通道畅通”
- 消防素养：指公民/个体/团体对消防安全的思想认识或者消防安全工作的“水平”“能力”“素养”等，如“公民的消防安全意识”。
- 福利保障：指公民享受的保障性权利。如“社会保险和福利待遇”，
- 经费支出：政府在公共设施建设或消防领域建设的投入及支出，或者财政方面的预算等。如“保障基本建设的投入”，“列入同级财政预算”
- 违法行为：指法律或消防规定禁止的行为。如“超越资质范围从事消防技术服务活动”，“非法转让资质”等。

- 履行义务：指法律规定的主体必须执行的行为。对应原文“必须”、“有……义务”等词语。

- 应当协助：指主体向其他主体给予协助或帮助。对应原文中“协助”“协调”等表示“帮助”的词语。

- 审批处理：指entity_1对entity_2实施“查处”“审批”“办理”这一类表示“处理”的动作。

## 核心原则：
- 不要做过度推理；只提取文本中明确表达或合理推导的关系

- 关系约束原则：提取的关系必须在entity_1和entity_2的语义共同约束之下。

- “应对缺失主语”的方法：对于缺失主语的句子，回看上一段落，从上下文推测缺失主语的指向。

- 去重与完整性检查：在最终输出前，请务必检查并删除所有完全重复的三元组。同时，请确保每一个三元组对象都包含entity_1, relation, entity_2这三个完整的键，无一缺失；禁止随意添加其他键。
- 三元组语序检查：在最终输出前，必须检查所有三元组的语序是否符合逻辑，是否符合原文。
**请严格遵循以下方法进行语序检查**：
1. 把entity_1, relation, entity_2的内容按顺序组合
2. 重新定位原文
3. 对比二者内容
4. 若三元组语序与原文语序不一致，则该三元组语序不正确。
- 重新提取策略：当发现语序错误，则触发“重新提取策略”。根据上下文修改`entity_1, relation, entity_2`，之后再次执行“三元组语序检查”，直至语序检查通过。
- 介词删除原则。当待提取的文本或者提取后的三元组包含“保证”“根据”“基于”“由”“在”等介词时，请忽略或删去其中的介词，保留“动词+名词”结构即可。
