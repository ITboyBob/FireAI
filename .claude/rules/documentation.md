# 文档撰写规则

## 语言规范

- 仓库内新增或修改的文档必须使用中文撰写。
- 禁止在文档系统中混用英文正文，除非引用不可翻译的专有名词、命令、路径或代码标识。

## 计划撰写规则

- 撰写任何类型的"执行计划"时，都必须显式说明本 Phase / Task 是否需要安装依赖。
- 若需要安装依赖，必须同时写明拟安装的依赖清单和安装环境。
- 若不需要，也应明确写成"无需新增依赖，沿用现有环境"。

## 文档系统一致性

- 新增、移动、重命名或删除文档时，必须同步 `docs/文档索引.md`。
- 改变文档读取时机或权威边界时，必须同步 `docs/文档读取规则.md` 和相关入口。
- Claude Code 专属文档不得覆盖根目录 `AGENTS.md`。
