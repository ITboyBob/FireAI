# Git 工作流规则

## 提交权限

- 允许代理在当前任务范围内执行 `git add` 与 `git commit`，用于记录本次已完成且已验证的改动。
- 提交后必须尽快同步提交范围、验证结果与实际提交说明，并明确未夹带无关改动。

## 禁止操作

未经用户单独要求，代理不得执行以下 Git 操作：

- `git push`
- `git merge`
- `git rebase`
- `git reset`
- `git checkout --`
- 其他改写历史、影响远端或可能误伤无关改动的操作

## 工作区保护

- 若工作区存在代理未产生的改动，代理必须避开这些改动。
- 若无法安全避开，必须先向用户说明风险，再决定是否提交。
