# 环境执行规则

## 强制规则

1. 所有包安装必须在 conda 环境 `fire` 中执行。
2. 所有代码执行必须在 conda 环境 `fire` 中执行。
3. 若当前 shell 不在 `fire` 环境，则不得直接运行 Python、pytest、脚本或服务启动命令。
4. 推荐使用 `conda run -n fire ...` 显式执行，避免误用 `base` 或系统 Python。

## 依赖管理

- 若实施计划或实际执行表明当前任务依赖尚未安装，必须先显式向用户请求并报备待安装的依赖清单。
- 仅在用户确认后，才可继续在 `fire` 环境自动安装。
